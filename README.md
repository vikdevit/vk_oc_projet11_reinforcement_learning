# OpenClassrooms — Projet 11 : Reinforcement Learning

## Présentation

Ce dépôt contient les travaux réalisés dans le cadre du projet 11 OpenClassrooms consacré au reinforcement learning (apprentissage par renforcement).

## Organisation du projet

- `notebooks/` : exercices et travaux de la mission.
- `src/` : scripts Python de l'application.
- `models/` : modèles entraînés et checkpoints locaux.
- `outputs/videos/` : vidéos de démonstration.
- `outputs/figures/` : graphiques générés.
- `outputs/metrics/` : métriques et résultats d'entraînement.
- `tests/` : tests.
- `docs/` : documentation.

## Environnement technique

L'environnement Conda existant est utilisé pour les travaux :

- Python 3.11
- PyTorch avec prise en charge CUDA

Les autres dépendances seront documentées après validation de l'environnement.
